# Success-story page review — hand-tuning punch list

Working tracker for the one-by-one review of all 46 story pages (started
20 Aug 2026, after the decor-aware extractor rework). The pipeline output is
good but not everywhere — this pass eyeballs each page against its printed
original and hand-tunes what the rules got wrong.

**Process, per page:** compare the live page against the printed page
(`public/flipbooks/success-stories/pages/NNNN.webp`). Fixes go, in order of
preference: (1) a rule fix in `extract_story_figures.py` if the defect is a
class, (2) the per-page escape hatches `CAPTION_OVERRIDE` / `DROP_FIGURE` /
`SPLIT_GROUP`, (3) template/curation changes. Never hand-edit generated
files — re-run `pnpm run data:stories` after each fix.
